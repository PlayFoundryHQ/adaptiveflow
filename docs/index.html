AdaptiveFlow

Adaptive, icon-first language flashcards for Android

Import any text, a YouTube link, a PDF or a plain word list. An AI provider you choose turns it into a spaced-repetition deck. Study, get an AI tutor on hard cards, keep a streak.

Download the APK Source on GitHub

What it does

Import → deck

Paste text or a word list, or load a PDF / TXT / CSV / JSON. Large PDFs are chunked and parsed page-by-page with automatic retry.

Adaptive study

An SM-2-style scheduler tracks each card. Struggle on one and it switches to multiple-choice; the tutor gets gentler.

AI tutor

Ask for pronunciation, usage examples or a simpler explanation, in the language you type in.

Master Vocabulary Pool

A single shared deck everything can merge into — with a preview of what's new vs. already there, and an undo.

Export anytime

Save a deck to JSON (re-imports for free) or CSV (opens in Anki). Building decks costs API tokens; keep the results.

English & Persian UI

The interface ships in English and فارسی. Pick Persian as your language and the whole app switches, right-to-left included.

Native TTS

Prefers Google's neural voices, picks the best voice for the target language, offers to install a missing language pack.

Bring your own key

AdaptiveFlow has no backend. Pick Google Gemini or DeepSeek and paste your own API key — it's stored encrypted on the device and excluded from cloud backup. When a key is set, the text you import and your tutor messages go directly to that provider under their terms. There is no analytics or telemetry. Without a key, the offline word: meaning list importer still works.

The loop

1 · ImportText, link, PDF or list
2 · ParseYour AI provider builds the deck
3 · StudyFlip, grade, adapt
4 · TutorAsk about the hard ones
5 · ProgressXP, streak, crowns

Under the hood

Kotlin + Jetpack Compose, single-Activity with navigation-compose and a small manual DI container. Room for decks / cards / SRS / progress (real migrations, exportSchema). A provider-agnostic AiProvider layer; the import pipeline and merge planner are pure and unit-tested. Full strings.xml with a Persian catalogue. Bleeding-edge toolchain by choice. One CI workflow: push to main builds a signed release APK. R8 + resource shrinking. Open source — see the repo.
